Rules

Start

Sun places the first Swan. Moon places the second Swan on a non-adjacent tile, then Moon takes the first turn.

Actions

Select an empty tile to place a Swan or Stone. Each player may have up to six Swans on the board. Once both players have six, each turn has two actions.

Movement

Select one or more Swans to move them one tile, or select adjacent enemy Swans to push them. Green is legal, red is illegal, and cyan or purple deselects.

Adjacent Stones follow. Shared Stones stay, and Stones adjacent to an enemy Swan stay.

Encirclement

Choking an enemy Swan's surrounding empty tiles encircles it. Encircled Swans freeze and can no longer move or spawn. Freezing an opponent's Swan grants one extra action for each Swan frozen.

Victory

When a player's last active Swan is encircled, that player loses. If both players' final active Swans are encircled during the same turn, the game is a draw.
